# ShellCrash 飞书机器人：镜像部署说明

本文适合在绿联 NAS、群晖 NAS、普通 Linux 主机上部署镜像版机器人。

## 1. 准备目录

示例：

```bash
mkdir -p /volume2/docker/shellcrash_feishu_bridging
cd /volume2/docker/shellcrash_feishu_bridging
```

绿联 NAS 注意：`.env` 是隐藏文件，文件管理器可能看不到，请优先用 SSH 修改。

## 2. 准备文件

镜像版部署最少需要：

```text
docker-compose.yaml
.env
```

也可以直接使用安装脚本：

```bash
sh install.sh
```

## 3. 手动部署方式

复制模板：

```bash
cp env.image.example.txt .env
cp docker-compose.image.yaml docker-compose.yaml
```

编辑 `.env`：

```bash
vi .env
```

必填项：

```env
BOT_IMAGE=ghcr.io/rocoer7/shellcrash-feishu-bot:latest
FEISHU_APP_ID=cli_xxxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxx
ROUTER_HOST=192.168.31.1
ROUTER_PORT=22
ROUTER_USER=root
ROUTER_PASSWORD=你的路由器SSH密码
ALLOW_ALL_USERS=false
ALLOWED_OPEN_IDS=你的open_id
```

初次测试时，可以临时：

```env
ALLOW_ALL_USERS=true
```

测试完成后建议改回：

```env
ALLOW_ALL_USERS=false
```

然后用 `/whoami` 获取自己的 open_id，填入：

```env
ALLOWED_OPEN_IDS=ou_xxxxxxxxx
```

## 4. 启动容器

```bash
docker compose up -d
```

如果 NAS 需要 sudo：

```bash
sudo docker compose up -d
```

## 5. 查看日志

```bash
docker logs -f shellcrash-feishu-bot
```

看到类似内容表示连接成功：

```text
connected to wss://msg-frontier.feishu.cn/...
```

## 6. 飞书测试

给机器人发送：

```text
/help
/whoami
/status
/menu
```

## 7. 更新镜像

```bash
docker compose pull
docker compose up -d
```

## 8. 停止或卸载

停止：

```bash
docker compose down
```

删除配置前请确认 `.env` 中没有还需要保留的信息。

## 9. 常见问题

### 文件管理器看不到 `.env`

这是正常的，点开头文件是隐藏文件。请用 SSH：

```bash
cd /volume2/docker/shellcrash_feishu_bridging
ls -la
vi .env
```

### 容器一直重启

查看日志：

```bash
docker logs --tail 100 shellcrash-feishu-bot
```

常见原因：

- `FEISHU_APP_ID` 或 `FEISHU_APP_SECRET` 没填
- `ROUTER_PASSWORD` 没填，且没有配置 `SSH_KEY_PATH`
- 飞书权限/事件没有发布

### 按钮没反应

检查飞书后台是否配置并发布：

```text
card.action.trigger
```

### 收不到消息

检查飞书后台是否配置并发布：

```text
im.message.receive_v1
im:message.p2p_msg:readonly
im:message.group_at_msg:readonly
im:message:send_as_bot
```
